# Ask Uncle Mike

Uncomplicate the world one question at a time.

Plain language. Lived experience first. No jargon to sound smart.
Audience: 18–40 and seniors. Anyone who would rather be shown than lectured.

Home: [github.com/michaelchaves-dev/Ask_Uncle_Mike](https://github.com/michaelchaves-dev/Ask_Uncle_Mike)
Studio pointer: [subtractarchitect.com](https://www.subtractarchitect.com)

This repo is the series bible and episode file tree. The channel is the public face.

## Subjects

| Folder | Name | What lives here |
|---|---|---|
| `01-fix-it` | Fix It | Hands-on repairs, adjustments, broken things, how-to tasks |
| `02-money` | Money | How money actually works, common sense, scams to watch |
| `03-learn` | Learn | School, skills, jobs vs tech, college fact vs fear |
| `04-life` | Life | Feelings, regulation, breathing and other tools that work |
| `05-you` | You | Health journey, body, habits — one person’s path, not a prescription |
| `06-tech` | Tech | Phones, computers, AI, the stack we actually use |

## Series rule

One episode = one question = one folder.
Fact labeled as fact. Story labeled as story. Opinion labeled as opinion.

See `series/YOUTUBE.md`.
